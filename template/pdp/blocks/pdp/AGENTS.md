# PDP block

Product name, SKU, price, availability, and media must come from a real catalog source. Do not invent merchandising or inventory claims. Map the selected variant before Add to Cart; PDP-only must not import checkout or PayPal. See `docs/commerce/pdp.md` and the [PDP agent guide](https://github.com/dylandepass/edge-commerce-agent-guides/blob/main/templates/pdp/CLAUDE.md) for authoring/accessibility guidance (not runtime code).
